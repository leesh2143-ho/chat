User API Room Management Room Interaction Socket.IO Events

API 명세서 (Node.js/Express) - 상세

이 문서는 Node.js Express 서버에서 처리하는 모든 HTTP RESTful API 엔드포인트와 Socket.IO 이벤트를 구체적으로 정의합니다. 각 항목을 클릭하여 세부 정보를 확인하세요.

1. User/Authentication Endpoints

사용자 인증 및 닉네임 생성과 관련된 API입니다.

서버에서 중복되지 않는 고유한 익명 닉네임을 생성하여 반환합니다.

요청 본문 (Request Body)

없음

200 OK - 성공 응답 (Success Response)

{
  "success": true,
  "nickname": "user-7541"
}

2. Room Management Endpoints

채팅방을 생성, 조회, 삭제하는 API입니다.

현재 서버에서 활성화된 모든 채팅방의 목록과 참여자 수를 반환합니다.

200 OK - 성공 응답 (Success Response)

{
  "success": true,
  "rooms": [
    {
      "roomId": "room-1234",
      "name": "General Chat",
      "userCount": 5
    },
    {
      "roomId": "room-5678",
      "name": "Dev Talk",
      "userCount": 2
    }
  ]
}

새로운 채팅방을 생성합니다. 생성 시 고유한 `roomId`가 발급됩니다.

요청 본문 (Request Body)

{
  "roomName": "string (Required)",
  "creatorNickname": "string (Required)"
}

201 Created - 성공 응답 (Success Response)

{
  "success": true,
  "room": {
    "roomId": "room-generated-uuid"
  }
}

400 Bad Request - 실패 응답 (Error Response)

{
  "success": false,
  "message": "필수 필드 누락 오류 메시지"
}

경로 파라미터로 전달된 `roomId`에 해당하는 채팅방을 삭제합니다.

200 OK - 성공 응답 (Success Response)

{
  "success": true,
  "message": "Room deleted successfully."
}

404 Not Found - 실패 응답 (Error Response)

{
  "success": false,
  "message": "Room을 찾을 수 없는 경우"
}

3. Room Interaction Endpoints

채팅방에 입장하거나 퇴장하는 API입니다.

특정 채팅방에 입장합니다. `socketId`는 클라이언트가 Socket.IO 연결 시 부여받는 고유 ID입니다.
로직: RoomID가 존재하지 않으면 자동으로 Room을 생성한 후 입장 처리됩니다.

요청 본문 (Request Body)

{
  "nickname": "string (Required)",
  "roomId": "string (Required)",
  "socketId": "string (Required)"
}

200 OK - 성공 응답 (Success Response)

{
  "success": true,
  "message": "Joined room successfully."
}

특정 채팅방에서 퇴장합니다.
로직: 퇴장 처리 후, Room에 남은 사용자가 0명이면 해당 Room은 자동으로 삭제됩니다.

요청 본문 (Request Body)

{
  "nickname": "string (Required)",
  "roomId": "string (Required)",
  "socketId": "string (Required)"
}

200 OK - 성공 응답 (Success Response)

{
  "success": true,
  "message": "Left room successfully."
}

4. Socket.IO 이벤트 명세

실시간 통신을 위한 Socket.IO 이벤트 목록입니다.

4.1. Client → Server (Emit)

현재 Room에 채팅 메시지를 전송합니다.

Payload (Data)

{
  "roomId": "string",
  "nickname": "string",
  "message": "string"
}

4.2. Server → Client (On)

새로운 채팅 또는 시스템 메시지(입장/퇴장)를 수신합니다.

Payload (Message Object)

{
  "type": "string ('chat' | 'system')",
  "roomId": "string",
  "sender": "string (e.g., 'user-7541' or 'System')",
  "text": "string (e.g., '안녕하세요!' or 'user-7541님이 입장하셨습니다.')",
  "ts": "string (ISO8601 Timestamp)"
}

`/api/room/join` 성공 직후, 해당 클라이언트에게만 최근 50개의 대화 기록을 전송합니다.

Payload (Data)

[
  { "type": "chat", "sender": "user-1234", "text": "...", "ts": "..." },
  { "type": "system", "sender": "System", "text": "...", "ts": "..." },
  ...
]

서버에 새로운 Room이 생성되었음을 모든 클라이언트에게 전파합니다. (Room 목록 갱신용)

Payload (Data)

{
  "roomId": "string",
  "name": "string",
  "userCount": 0
}

Room이 삭제되었음을 모든 클라이언트에게 전파합니다. (Room 목록 갱신용)

Payload (Data)

{
  "roomId": "string"
}
